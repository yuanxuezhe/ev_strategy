# 01 项目总览

> 源码：`evtrade/` 包（包结构见 §6 与 12 号文档）

## 1. 项目定位

一个**回测 / 实盘统一架构**的量化交易演示框架：

- 数据源：MySQL `evtrade` 库的 `minute_bars` 表（1 分钟原始行情）
- 核心能力：**周期合并**（1m → 任意 `m/h/d` 周期）+ **EMA 通道偏离策略**
- 目标：同一套引擎代码，回测跑历史、实盘接实时，只换"行情源"和"下单器"两个组件

分层（数据 → 合并 → 策略 → 执行）：

```
bar 流 (行情源)  ──yield Bar──▶ Engine
                                 │
                            BarAggregator (周期合并, 独立于策略)
                                 │ on_bars(周期K线集合)
                                 ▼
                       ChannelDeviationStrategy + ema_channel(指标)
                                 │ signal
                                 ▼
                            Executor (模拟/真实下单) → Account (资金持仓)
```

**切换实盘/回测：换 bar 流 + 换 Executor，其余不变。**

## 2. 核心特性

1. **纯增量计算**：周期合并 O(1)/根，EMA 通道 O(1)/桶（`ema_channel_step`），可支撑实盘逐根推送
2. **前开后闭、右端点标注**的合并桶时间戳（与通达信等主流行情软件一致），详见 04 文档
3. **预热机制**：策略起始日之前默认再拉 365 天数据做指标预热（`mark=0`），策略期（`mark=1`）才驱动交易
4. **锁存式策略**：极端偏离置位 → 回撤确认触发，天然带迟滞（hysteresis），避免边界反复触发
5. **单桶单操作**：同一根周期 K 线内每个方向最多一次状态转换，防止桶内 H/L 大幅波动反复打信号
6. **组件解耦**：行情源、合并器、指标、策略、账户、下单器全部独立，可单独替换
7. **基线对比**：回测汇总同时给出"策略总资产"与"不操作基线"，直接看出策略超额盈亏

## 3. 技术栈与依赖

| 项 | 说明 |
|---|---|
| 语言 | Python 3（使用了 `from __future__ import annotations`、`dataclass`、`dict \| None` 联合类型语法，建议 3.10+） |
| 数据库驱动 | `pymysql` |
| ORM/连接 | `sqlalchemy`（`create_engine`，`pool_pre_ping` + `pool_recycle=3600`，在 `core/data.py::_fetch` 内延迟 import） |
| 批量取数 | `pandas`（`pd.read_sql`，在 `core/data.py::_fetch` 内延迟 import） |
| 数值/向量化 | `numpy`（合成数据、指标批量参考实现） |
| 标准库 | `argparse`、`dataclasses`、`datetime`、`typing`、`functools.lru_cache` |

安装：

```bash
pip install pymysql sqlalchemy pandas
```

## 5. 快速上手

```bash
# 回测 (CPU 后端, 默认 5m 周期)
python -m evtrade backtest --period 5m --start 20250101 --end 20260903 --device cpu

# 换标的 / 换周期 / 调策略参数
python -m evtrade backtest --period 1h --code 513120.SH --params "low1:2;low2:1.2"
```

运行后输出：数据加载进度（`core/data.py::load_bars` 打印）→ 信号行（策略触发时打印完整指标快照）→ 回测盈亏汇总（`core/metrics.py::summarize`）。输出解读见 10 文档。
