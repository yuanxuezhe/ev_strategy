# 07 账户与执行器

> 相关源码：`Account`（`mysql_analyze_demo.py:332-361`）、`Executor` 层次（`mysql_analyze_demo.py:366-418`）

## 1. `Account` —— 资金/持仓记账（回测/实盘共用）

### 字段

| 字段 | 含义 |
|---|---|
| `init_cash` / `init_position` | 期初资金 / 期初持仓（快照，算基线用） |
| `cash` / `position` | 当前现金 / 当前持仓股数 |
| `trades` | 交易流水 `list[dict]`：`{"ts", "side", "qty", "price"}` |
| `last_price` | 最新价（由 Engine 在策略期每根 bar 更新），权益估值用 |

### 方法

**`apply(side, qty, price, ts)`** —— 纯记账，不含任何下单逻辑，由 Executor 在"确认成交"后调用：

- `BUY`：`cash -= qty*price`，`position += qty`
- `SELL`：`cash += qty*price`，`position -= qty`
- 追加一条 trade 流水

注意：不校验资金/持仓是否足够（前置检查在 Executor 里做）；不考虑手续费、滑点、印花税（当前模型为理想化成交）。

**`equity(price=None)`** —— 策略总资产 = `cash + position × price`（不传价则用 `last_price`）。

**`baseline_equity(price=None)`** —— **不操作基线** = `init_cash + init_position × price`。
含义："如果期初之后什么都不做，现在值多少"。回测汇总用 `策略总资产 - 基线` 得策略盈亏（见 09 文档 `print_summary`）。

## 2. `Executor` —— 下单抽象

```python
class Executor:
    def trade(self, signal: str, price: float, ts: str) -> bool: raise NotImplementedError
```

策略/引擎只调 `executor.trade(signal, price, ts)`，不关心背后是模拟还是真实委托。返回 bool 表示是否成交。

### 2.1 `SimulatedExecutor`（回测用）

成交模型（`mysql_analyze_demo.py:381-401`）：

- **成交价**：信号当根的最新 close（Engine 传入的 `price = cur["close"]`）
- **BUY 数量**：`min(每笔qty, cash/price)` —— 固定买 1 万股；资金不足则**用剩余资金买满**
- **SELL 数量**：`min(每笔qty, position)` —— 固定卖 1 万股；持仓不足则**清掉剩余持仓**
- 数量 ≤ 0（没钱/没票/价格为 0）→ 不成交，返回 False
- 成交后调 `account.apply(...)`，verbose 模式打印带剩余资金/持仓的成交行

### 2.2 `BrokerExecutor`（实盘占位）

当前是占位实现（`mysql_analyze_demo.py:404-418`）：

- 打印 `[LIVE] BUY/SELL ... (未接入券商)`，返回 False（视为未成交）
- 注释中预留的接入路径：

```python
# order_id = self.broker.place_order(signal, self.qty, ...)
# 成交回报后调 self.account.apply(...) 记账
```

接入实盘时的要点：

1. `place_order` 建议异步化：真实成交是回报驱动的，`trade()` 返回 True 的时机应是**成交回报**到达时；期间状态由券商侧为准
2. 记账时机 = 成交回报，价格 = 实际成交均价（而非信号价）
3. 需处理拒单/部分成交/撤单等分支（当前 `apply` 模型只有全额成交一种）
4. 手续费/滑点应在 `apply` 或其外层补记

## 3. 数量与资金约定

| 项 | 默认值 | 说明 |
|---|---|---|
| INIT_CASH | 200000.0 | 期初资金 20 万（`mysql_analyze_demo.py:630`） |
| INIT_POSITION | 200000.0 | 期初持仓 **20 万股**（`mysql_analyze_demo.py:631`）——有底仓，SELL 信号才有票可卖 |
| TRADE_QTY | 10000.0 | 每次信号交易 1 万股（`--trade-qty` 可调） |

这个配置意味着：策略是"在 20 万股底仓上做 1 万股级别的择时加减仓"，基线 = 20 万现金 + 20 万股按期末价的市值。

## 4. 账务口径小结

- 权益 = 现金 + 持仓 × 最新价；`last_price` 只在策略期（mark=1）更新，预热期不动
- 盈亏口径 = 策略期末总资产 − 不操作基线（同一期末价估值，消除行情涨跌的影响，只留择时贡献）
- 无手续费/滑点模型；对比实盘结果时应预期回测偏乐观
