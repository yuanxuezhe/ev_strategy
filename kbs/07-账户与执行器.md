# 07 账户与执行器（策略自负责）

> 2026-09-13 重构：**framework 不再持有资金/持仓/撮合/账本概念**；
> `Account` / `Executor` / `SimulatedExecutor` / `trade_decision` 已从 framework 删除；
> 本节说明**策略 `step` 内部如何自管**资金/持仓/撮合（每个策略各写一份，不抽取共享）。
>
> 相关源码：`evtrade/strategies/channel_deviation.py` / `ma_crossover.py` / `filtered_mr.py`
> （每个策略文件内 inline `_trade_decision` 函数 + state 字段 `cash / position / trades`）

## 1. 策略自管：state 字段 + 撮合数学

每个策略的 `@dataclass` state 内含：

| 字段 | 含义 |
|---|---|
| `cash` / `position` | 当前现金 / 当前持仓股数 |
| `init_cash` / `init_position` | 期初快照（由 `init_state` 写入） |
| `trades` | 结构化成交 list `[{ts, side, qty, price}]` |

策略 `step` 内部：

```python
# 策略内联 (与旧 evtrade.execution.base.trade_decision 等价)
def _trade_decision(side, price, cash, position,
                    cur_qty, buy_pct, sell_pct):
    if side > 0:
        max_by_cash = cash / price if price > 0 else 0.0
        if buy_pct > 0:
            q = min(buy_pct * max_by_cash, max_by_cash)
        else:
            q = min(cur_qty, max_by_cash)
        if q <= 0:
            return cash, position, 0.0, False
        return cash - q * price, position + q, q, True
    if sell_pct > 0:
        q = min(sell_pct * position, position)
    else:
        q = min(cur_qty, position)
    if q <= 0:
        return cash, position, 0.0, False
    return cash + q * price, position - q, q, True
```

`step` 内部当 sig != 0 时调上述函数，更新 `state.cash / state.position / state.trades`。

> 撮合数学与旧 `evtrade.execution.base.trade_decision` 等价（bitwise 一致），只是从 framework 下放到每个策略文件内 inline 实现。

## 2. 资金模式参数（走 `--params`）

| 参数 | 含义 |
|---|---|
| `init_cash` | 期初资金（默认 200000） |
| `init_position` | 期初持仓股数（默认 0） |
| `trade_qty` | 每次信号交易股数（默认 10000） |
| `buy_pct ∈ [0,1]` | BUY 时按当前 `cash` 的比例下注（0=关闭走 `trade_qty`） |
| `sell_pct ∈ [0,1]` | SELL 时按当前 `position` 的比例卖（0=关闭走 `trade_qty`） |

CLI 不再有 `--init-cash --buy-pct --sell-pct --all-in --trade-qty` flag；全部走 `--params`：
```bash
python -m evtrade backtest --strategy channel_deviation \
    --params "init_cash:200000;trade_qty:10000;buy_pct:0.5"
```

## 3. 自管示例（channel_deviation 节选）

```python
@dataclass
class ChannelDeviationState:
    ema: EMAChannelState = field(default_factory=EMAChannelState)
    fsm: DeviationFSM = field(default_factory=DeviationFSM)
    # ... 其它 EMA/FSM 字段
    # 资金/持仓/账本 (策略自管)
    cash: float = 0.0
    position: float = 0.0
    init_cash: float = 0.0
    init_position: float = 0.0
    trades: list = field(default_factory=list)

def init_state(self, params):
    st = ChannelDeviationState()
    st.init_cash = float(params["init_cash"])
    st.init_position = float(params["init_position"])
    st.cash = st.init_cash
    st.position = st.init_position
    return st

def step(self, state, bar, params):
    # ... EMA / FSM 算 sig
    if sig != 0:
        new_cash, new_pos, q, filled = _trade_decision(
            sig, bar["c"], state.cash, state.position,
            params["trade_qty"], params["buy_pct"], params["sell_pct"])
        if filled:
            state.cash = new_cash
            state.position = new_pos
            state.trades.append({"ts": bar["ts"],
                                 "side": "BUY" if sig > 0 else "SELL",
                                 "qty": q, "price": bar["c"]})
    return state, sig
```

## 4. framework 不提供 / 不识别

- ❌ `Account` 类
- ❌ `Executor` / `SimulatedExecutor` 类
- ❌ `trade_decision` 函数（framework 路径）
- ❌ `metrics.summarize` / `equity` / `cagr` / `sharpe` / `drawdown` 等 PnL 字段
- ❌ `apply(side, qty, price, ts)` 类记账方法
- ❌ `--init-cash --buy-pct --sell-pct --all-in --trade-qty --warmup-days --data-cache` CLI flag
- ❌ `replay` 子命令 + `--against-ref`

要看 PnL / 收益 / 绩效请在策略代码内自加 state 字段（如 `equity_curve / cagr / sharpe`）或自提供打印 hook。

## 5. 自定义实盘执行器

> 2026-09-13 后 framework 不提供 `Executor` 基类。实盘接入需要策略**自己写撮合与记账**——
> 直接在策略 `step` 内调自己的撮合数学即可。例：

```python
class MyLiveStrategy(VectorizedStrategy):
    def step(self, state, bar, params):
        # ... 算法
        if sig != 0:
            # 调真实券商 API
            order = broker.place_order(sig, bar["c"], bar["ts"])
            # 等待成交回报 (此处简化, 实际需要回报回调)
            actual_qty, actual_price = order.fill_qty, order.fill_price
            state.cash += -actual_qty * actual_price if sig > 0 else actual_qty * actual_price
            state.position += actual_qty if sig > 0 else -actual_qty
            state.trades.append({...})
```

实盘回测用同一份策略代码（仅 step 内撮合调用替换），不需 framework 提供 Executor 基类。
